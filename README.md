A small reproduction of SomeVer 0.1.2 writing the last template’s contents
into every output. The project has two templates: one plain-text version
file and one XML configuration. All paths are relative to the project root.

Requires Git, .NET SDK 10, and Python 3.

```sh
git clone https://github.com/computerquip-work/somever-template-repro.git
cd somever-template-repro
dotnet build Version.verproj
python3 check.py
```

The build succeeds, but the check fails: `generated/version.txt` contains
XML instead of `Version=1.2.3`. `generated/config.xml` contains the expected
XML. The `v1.2.3` Git tag supplies the version; keep it when cloning.

The check asserts the intended outputs and passes when the template target
is batched by `OutputPath`. The reproduction and check were generated by AI.
